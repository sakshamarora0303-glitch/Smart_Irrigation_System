# Smart Irrigation Prediction System

## Project Overview
A machine learning-based irrigation system that uses soil moisture and environmental data to predict when a plant needs watering.

## Objectives
- Analyze soil moisture and weather data.
- Train a machine learning model for irrigation prediction.
- Connect the model to an ESP32 for automated pump control.

## Technologies
- Python
- Pandas and NumPy
- Scikit-learn
- PyTorch (for later experiments)
- ESP32

Development in progress.
